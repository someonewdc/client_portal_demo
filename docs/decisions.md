# Решения

| ID    | Область       | Решение                                                                                                                                                                                                                                                             |
| ----- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-001 | Workspace     | Новый репозиторий `client_portal_demo` рядом с Вольтарисом, не fork `apps/*`.                                                                                                                                                                                       |
| D-002 | Scope пакетов | Private `@client-portal/*@0.0.0`. Registry и license не выбирались.                                                                                                                                                                                                 |
| D-003 | Mock          | `mock-core` и отдельный mock-api не входят и не появятся. Заявки = Postgres + seed.                                                                                                                                                                                 |
| D-004 | Каркас API    | Health в заготовке. Предметный MVP — по `docs/llm/feature-NN.md`.                                                                                                                                                                                                   |
| D-005 | Имя завода    | ПК «Нордщит». Не «Вольтарис», витрину Вольтариса не цитировать как этот продукт.                                                                                                                                                                                    |
| D-006 | Порты         | Web `http://localhost:3000`, API `3001` (уже в `.env.example`). **Один стенд на машине** для `:3000`/`:3001`: Вольтарис и это демо одновременно не поднимать. Postgres на хосте **5433** (в контейнере 5432), имена compose/container с префиксом `client-portal-`. |
| D-007 | Статусы       | Enum: `accepted` → `in_calculation` → `quote_ready` → `invoice_issued`. Подписи: Принят, В расчёте, КП готово, Счёт выставлен.                                                                                                                                      |
| D-008 | Секрет        | Opaque base64url как `generateOpaqueToken`; в БД только `hashOpaqueToken`. Сиды — стабильные fixture из `docs/domain-model.md`. Секрет = capability, не пользователь. Кабинет `/r/{accessSecret}`.                                                                  |
| D-009 | Файлы         | Только метаданные в seed. Нет upload и нет кнопки «скачать».                                                                                                                                                                                                        |
| D-010 | Prisma        | Prisma 7 ESM в `apps/api`, `prisma.config.ts`, client `apps/api/src/generated/prisma`, PostgreSQL driver adapter.                                                                                                                                                   |
| D-011 | Nuxt          | Nuxt 4 + Tailwind v4 `@theme` + generated `packages/api-client`. Патч-версии — по lockfile и официальным docs в чате фичи 3, не угадывать заранее.                                                                                                                  |
| D-012 | TDD           | Тесты по AC до кода; red evidence обязателен. E2E-сценарии пишут в фичах 4–5 до страниц (harness — фича 3). Тест, зелёный до реализации поведения, — false positive.                                                                                                |
| D-013 | Lifecycle     | Агентам — цели корневого Makefile, когда они есть. Не сырой `pnpm dev` / `docker compose` в промптах, кроме skill.                                                                                                                                                  |
