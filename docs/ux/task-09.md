## Контекст продукта

ПК «Нордщит». Имена сидов с `.pdf` остаются. Нет кнопки «скачать», `[download]`, `#`.

Фиксированная строка сразу под `h2`/`heading` «Файлы»:

`Имя открывает выписку на экране.`

Кликабельно только имя (как D-029). Тип (`Опросный лист` / `КП` / `Счёт`), размер,
дата — не ссылки.

Ритм: у каждого `li` одна сетка (`flex-wrap` с `basis` или CSS grid), чтобы дата не
уезжала на вторую строку у одной записи и оставалась в строке у другой без системы.
На 390px перенос после имени допустим, если **все** записи переносятся одинаково.
