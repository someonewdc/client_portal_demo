## Контекст продукта

ПК «Нордщит». HTTP 404 для обоих тупиков остаётся. Логина нет.

Фиксировано:

| Случай                 | h1                       | Пояснение                                                                            | Ссылка                    |
| ---------------------- | ------------------------ | ------------------------------------------------------------------------------------ | ------------------------- |
| неизвестный секрет     | `Ссылка недействительна` | `Заявки по этой ссылке нет. Проверьте адрес или попросите новую ссылку у менеджера.` | нет (не на `/`)           |
| заявка есть, файла нет | `Ссылка недействительна` | `Такого документа в заявке нет. Откройте заявку и выберите имя из списка.`           | `К заявке {publicNumber}` |

На обоих 404 **нет** строки `Код ошибки:` (UUID). Для 5xx загрузки заявки
`Код ошибки` + `traceId` оставь как сейчас.

Title 404 (задача 2): `Ссылка недействительна — ПК «Нордщит»`.
