# Сценарии демо

Ведущий поднимает показ через Makefile, когда цели есть: `make up` — полный стенд
web+api+postgres (D-016); `make dev` — Postgres из compose и api/web на хосте; `make restart`
— гасит контейнеры и leftover `node` на портах стенда (не Docker Desktop), затем снова `dev` (D-028). Канонический origin:
`http://localhost:3000`. Один стенд на машине для `:3000`/`:3001`.

Кабинет в шаге 4 и различение тупиков в «Битая ссылка» — целевой показ после
UX-задач 1–20 (`выполни ux задачу N` / `реализуй ux задачу N`). До merge 1–12
стенд показывает кабинет фич 10–13 (заголовок = номер, один текст 404, UUID на
тупике). Сетка и ссылки в покое — после 13–18. Иерархия документа (шкала ролей
и summary list) — после 19–20.

## Счастливый путь (30 секунд)

1. Открыть `/`. Увидеть заголовок «Ссылки для показа», дисклеймер: список не для заказчика,
   подпись про мессенджер, инструкцию нажать строку.
2. В списке — сиды ПК «Нордщит» (номера, контрагенты, штампы статусов).
3. Клик по строке, например «КП готово» (З-10043) — переход на `/r/seed-z10043-quote-kuznetsov`
   без копирования ссылки.
4. Кабинет: «Статус заявки», **h1 «КП готово»**, номер, фраза что менеджер прислал
   ссылку и вход не нужен, подписанные заказчик / изделие / обновлено (без штампа у
   даты), фраза «Коммерческое предложение готово. Счёт ещё не выставлен.», лента 1–4
   с датами до «КП готово» и «ещё нет» на счёте, спецификация не-SKU, файлы как записи
   и строка «Нажмите имя файла — откроется выписка на экране.». Клик по имени КП открывает HTML-лист
   (выписка, не download); «К заявке» возвращает в кабинет. Скачивать нечего. На
   телефоне лента и спека читаются без обрезки.
5. По желанию открыть другую ссылку (принят / счёт), чтобы показать разные шаги.

Зритель должен унести: «вот что увидит заказчик по ссылке».

## Битая ссылка

1. Открыть `/r/this-secret-does-not-exist` (или любой неизвестный секрет).
2. Понятный тупик на русском («заявки нет»). Нет формы входа, телефона, OTP,
   «зарегистрироваться», нет UUID на экране.
3. API на тот же секрет — 404 Problem Details.
4. Чужое имя файла при живой заявке — другой текст («документа нет») и ссылка
   «К заявке», не «заявки нет».

## Не показывать

Рассылку писем, копирование ссылки как основной жест, админку статусов на кабинете
заказчика, каталог SKU, чат, логин на пульте.

## Живой показ (после фич 29–33)

Снепшотный путь индекса выше остаётся. Рядом — live:

1. Открыть `/start`. Увидеть h1 «Подать заявку», два абзаца D-055 и одну кнопку.
2. Клик «Подать заявку» — кабинет З-10046, статус «Принят», без логина.
3. На другом экране открыть пульт `/c/{conductorSecret}` (ссылка «Пульт показа»
   с индекса). Фраза: экран не показывается заказчику.
4. «Продвинуть заявку» — кабинет живой заявки сам (после F33) или после
   навигации показывает «В расчёте», затем «КП готово», затем «Счёт выставлен».
   На счёте ещё одно «продвинуть» не меняет заявку.
5. «Сбросить» или снова «Подать заявку» — снова «Принят», только опросный лист.
6. Каталожные пять на индексе не меняются. На кабинете заказчика кнопок пульта нет.
