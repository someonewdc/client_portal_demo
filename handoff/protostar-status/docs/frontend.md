# Frontend

Страница заявки — **документ**, не лендинг Protostar и не витрина Вольтариса.

Лендинг (`Bounded`, стекло, градиент) на `/r/{secret}` не копировать: заказчик
должен читать заявку, а не рекламу студии. Шапка может нести слово Protostar как
поставщика экрана (бренд уже в layout после генератора), не CTA «написать
основателю».

## Референсы (те же, что оправданы для статуса)

- Stripe hosted invoice: длинный URL, номер, статус, файлы списком, воздух.
- USWDS process list: вертикальные шаги-штампы, не wizard.
- NHS Tag: статус не кликается.

Не брать: каталог Вольтариса, Integration Lab, glass hero сайта, SaaS-дашборд.

## Запрещено

Glassmorphism, bento, неон, 3D, тёмная «кибер» тема, канбан, графики KPI,
hero-магазин, стоковый «AI dashboard».

## Токены

Генератор уже принёс IBM Plex Sans и бумажный `@theme`. Для v1 **оставить**: это
документ, не маркетинг. Не подключать Google Fonts CDN. Не Inter.

Русский язык: «ё», кавычки «», тире —. Без канцелярита «осуществляется». Кнопки
статуса на кабинете заказчика нет.

Индекс `/`: один абзац, куда делась ссылка. Не «Ссылки для показа».
