# Приёмка артефакта продажи

Отмечать только после факта (браузер или HTTP), не «по коду видно».

- [ ] `GET /api/v1/health/live` и `/ready` на стенде dest → 200 при поднятой БД.
- [ ] Секрет примера открывает кабинет: номер, контрагент, title щита/комплекта,
      лента из четырёх шагов, 2–5 строк спеки, список файлов.
- [ ] Чужой секрет → тупик, не форма входа.
- [ ] Имя файла открывает HTML-лист в том же окне.
- [ ] На кабинете нет кнопок смены статуса, чата, логина, каталога, «Вольтарис»,
      «Нордщит», «Ссылки для показа».
- [ ] Индекс `/` не перечисляет заявки.
- [ ] Покупатель Protostar за 30 секунд понимает: «это отдадут моему клиенту».
- [ ] Лендинг `protostar.ru` не сломан и не проксирует этот API.
