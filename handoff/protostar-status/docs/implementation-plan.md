Не фичи 1–33 Нордщита. Задачи этого git — `docs/llm/task-NN.md`, оператор
`реализуй задачу N`. Зависимость: D-004 закрыт до кода задачи 1; D-008 закрыт до
задачи 3; D-002 закрыт до задачи 4 (nginx живёт в `protostar_site`, не здесь).

```text
Задача 1  пример заявки в seed + кабинет показывает её
Задача 2  листы файлов по kind (опрос / КП / счёт) на этой заявке
Задача 3  оператор создаёт и двигает статус (D-008)
Задача 4  спецификация хостового nginx для status.* (чат в protostar_site)
```

Не входит ни в одну задачу: каталог SKU, чат, OTP, 1С, amo, mint TLS-сертификатов
как сервис, лендинг Astro, театр Нордщита, копирование Вольтариса, публикация npm.

Код ради «платформы кабинетов» запрещён. Допустимо: артефакт к письму (одна
сделка, ссылка, четыре статуса) и позже адаптер под первого платящего — отдельным
решением после D-015.
