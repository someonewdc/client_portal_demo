# Доменная модель

Одна не‑SKU заявка. Нет пользователя, роли и сессии заказчика: доступ — знание
секрета.

## Заявка (то, что видит страница)

- `publicNumber` — человекочитаемый номер. Не копировать `З-1004*` Нордщита.
  Префикс и первый пример — D-004 / задача 1.
- `counterpartyName` — ЮЛ/ИП заказчика завода (вымысел для артефакта продажи).
- `title` — щит / НКУ / комплект, не артикул с полки.
- `status` — текущий шаг enum ниже.
- `updatedAt` — последнее изменение заявки.
- `specLines` — ровно 2–5 строк: `name`, `quantity` (integer), `unit`,
  необязательный `comment`. Не корзина каталога, не типы цен.
- `files` — метаданные: `fileName`, `kind` (`questionnaire` / `quote` /
  `invoice`), `byteSize` (integer), `uploadedAt`, `specLines` документа (2–5
  строк). Бинарников и upload с диска в v1 нет. Имя открывает HTML-лист.
  В одной заявке `fileName` уникален.
- `stageHistory` — когда заявка достигла каждого пройденного статуса.

Внутренние:

- `id` — суррогат.
- `accessSecretHash` — SHA-256 hex opaque-секрета. Уникален. Plaintext в БД нет.

Денежные суммы в v1 не обязательны. Если появятся — integer minor units, не float.

## Статусы

Линейная лента. API enum — латиница; подписи — русский.

| Enum             | Подпись        |
| ---------------- | -------------- |
| `accepted`       | Принят         |
| `in_calculation` | В расчёте      |
| `quote_ready`    | КП готово      |
| `invoice_issued` | Счёт выставлен |

Текущий статус — последний достигнутый. Лента: все четыре штампа (пройден /
текущий / ещё нет). Не канбан. В HTTP `stages` всегда четыре элемента в этом
порядке; будущие — `reachedAt: null`.

## Секрет

- Алфавит `generateOpaqueToken()`: base64url `[A-Za-z0-9_-]`.
- Lookup: `hashOpaqueToken(secret)` → уникальный индекс.
- Секрет — capability одной заявки.
- Кабинет (dev): `http://localhost:3100/r/{accessSecret}`.
- Лист: `http://localhost:3100/r/{accessSecret}/d/{fileName}`.
- Публичный origin — D-002.

## Seed v1

Одна примерная заявка-артефакт (задача 1). Не пять каталожных + живая З-10046.
Не `REQUEST_CATALOG` Нордщита. Повторный seed идемпотентен: тот же секрет и номер,
без CSPRNG на каждый прогон.

Имя вымышленного контрагента и `publicNumber` — D-004. Пока решение открыто, код
примера не писать.
