# Решения

Следующий свободный ID — **D-016**. Открытые строки нельзя закрывать кодом: сначала
явный prompt оператора, потом эта таблица.

| ID    | Тема                      | Решение                                                                                                                                                                                              |
| ----- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-001 | Вид страницы              | Документ (бумага, IBM Plex из генератора). Не стекло лендинга Protostar и не каталог Вольтариса.                                                                                                     |
| D-002 | Публичный hostname        | **Открыто.** Предложение: sibling `https://status.protostar.ru` (web `/`, API `/api/v1/`), как demo/show, не path на `protostar.ru`. Cutover только после DNS/TLS и HTTP 200. Пока — localhost:3100. |
| D-003 | Театр Нордщита            | Нет `/demo/links`, `/start`, `/c/`, `demoLive`, `З-1004*`, «Ссылки для показа».                                                                                                                      |
| D-004 | Пример заявки             | **Открыто.** Один вымышленный контрагент + `publicNumber` + стабильный fixture-секрет. Не «Нордщит», не «Вольтарис». Не писать seed, пока оператор не назвал номер и имя.                            |
| D-005 | Доступ                    | Opaque-секрет в URL, hash в БД, нет логина заказчика.                                                                                                                                                |
| D-006 | Порты dev                 | Web 3100, API 3101, Postgres 5434. Не 3000/3001/5433.                                                                                                                                                |
| D-007 | Сессия                    | Cookie и HTTP 401 для заказчика запрещены.                                                                                                                                                           |
| D-008 | Как менеджер кормит экран | **Открыто.** Варианты: CLI от env-секрета оператора; узкий HTTP с тем же секретом. Не пульт показа и не amo в v1.                                                                                    |
| D-009 | SKU                       | Если можно купить карточкой с ценой — out. Спека 2–5 строк состава.                                                                                                                                  |
| D-010 | Apex                      | `protostar.ru` остаётся Astro. Этот сервис туда не проксировать.                                                                                                                                     |
| D-011 | Вольтарис                 | Вымысел для созвона, не кейс, код не копировать.                                                                                                                                                     |
| D-012 | Деньги                    | Суммы диагностики/экрана/ретейнера на эту страницу и в API v1 не выносить.                                                                                                                           |
| D-013 | Seed                      | Одна заявка-артефакт, не каталог пяти + live.                                                                                                                                                        |
| D-014 | Ошибки                    | RFC 7807. Секрет не в `instance` и не в логах.                                                                                                                                                       |
| D-015 | Scope npm                 | `@protostar/*`, имя workspace `protostar-status`, бренд Protostar.                                                                                                                                   |

## Не угадывать

Hostname (D-002), имя примера (D-004), канал менеджера (D-008). Если prompt просит
реализовать задачу 1 без D-004 — остановиться и спросить.
